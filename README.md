The Green Ledger

A java console application designed to help a small plant nursery track plant sales, business expenses and financial transactions.

Created for a capstone project.

Features

Record plant sales and nursery expenses.

Save and load transactions using a CSV file.

View deposits, payments, and all transactions.

Sort transactions from newest to oldest.

Generate monthly and yearly financial reports.

Search transactions by customer or vendor.

Technologies

Java 17

IntelliJ IDEA

Maven

Git & GitHub

How to Run

Open the project in IntelliJ IDEA.

Run AccountingLedger.java.

Follow the console menu to record transactions or view reports.
